# INTRODUZIONE

---

Unlike other categories (which each group 3+ genuinely separate services — three mail protocols, three database engines, etc.), **Web browsing is structurally just HTTP and HTTPS** on the CompTIA N10-009 objective 1.4 list. It's a real two-item category, not an incomplete one.

If you want the conceptual picture beyond the strict exam scope, worth knowing (but not adding as a "protocol" per se):

- **HTTP/2** and **HTTP/3** are newer _versions_ of HTTP, not separate protocols with their own ports — HTTP/3 is the interesting one since it runs over **QUIC on UDP port 443** instead of TCP, but CompTIA doesn't test this distinction.

Two things that might feel like they belong here but are correctly placed elsewhere in your vault:

- **DNS** — every web page load starts with a DNS lookup, but the protocol's _job_ is resolution, so it stays in Addressing & directory lookups.
- **FTP** — same web-adjacent instinct, but it's a distinct transfer protocol with its own ports (20/21), so it stays in file transfer.

If your professor's course material genuinely lists a third web protocol, let me know which one and I'll help you place it correctly — but for the official Network+ objective, HTTP/HTTPS is the whole category.
