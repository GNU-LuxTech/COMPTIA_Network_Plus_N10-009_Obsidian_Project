# INTRODUZIONE 

---

Parte fondamentale dello studio per il [[COMPTIA NETWORK+ N10-009]] i modello ISO/OSI che significa Open System Interconnection, creato dalla [[International Organization for Standardization]] nel 1984 è un [[FRAMEWORK]] concettuale che standardizza le funzioni delle telecomunicazioni in 7 diversi livelli.
