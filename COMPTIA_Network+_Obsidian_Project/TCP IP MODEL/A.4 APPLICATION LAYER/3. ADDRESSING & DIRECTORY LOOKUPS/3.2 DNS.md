# INTRODUZIONE

---

Riguardo DNS ne esistono 3 varianti le quali utilizzano sia TCP che UDP:

1. Plain DNS su porta 53 TCP il quale comunica in cleartext ( un vero problema di sicurezza e privacy ).
   
2. DoT ( DNS over TLS ) ===RFC 7858===, Il quale cripta le DNS queries e risponde usando certificati TLS così che nessuno sniffando il traffico possa vedere quali domini stiano venendo risolti.
   
3. DoH ( DNS over HTTPS ) ===RFC 8484=== stesso obiettivo di DoT ma con un processo diverso, cripta il traffico DNS e reindirizza le DNS queries all'interno di HTTPS Requests cosicché il traffico DNS sembri normale traffico HTTPS.
   
>[!note]
Per gli amministratori di rete DoH è molto più difficile da distinguere e/o selezionare cosi da bloccare eventuale traffico DNS dal resto del web-browsing traffic, il quale è un grande punto di dibattito dato che può bypassare DNS-Based Filtering.
