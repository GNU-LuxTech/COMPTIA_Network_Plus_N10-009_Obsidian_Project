# INTRODUZIONE

Il modello TCP/IP (versione più moderna rispetto al [[ISO OSI Model]], standardizzata con [RFC 1122](https://www.rfc-editor.org/info/rfc1122/) è anch'esso un framework fondamentale per il networking moderno, definisce come i dati vengono trasmessi fra diversi sistemi interconnessi, consiste di 4 maggiori livelli, alle volte rappresentati nella versione estesa da 5 livelli, che lavorano insieme per assicurare comunicazioni affidabili.
