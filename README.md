> Created and maintained by **Mattia Vacca** · [GNU-LuxTech](https://github.com/GNU-LuxTech)

---

## 📖 About

This vault is a personal study reference covering the full CompTIA Network+ N10-009 exam objectives. Notes are organized hierarchically following the **TCP/IP model** and the **ISO OSI model**, with each layer broken down into its relevant protocols and technologies.

All notes are written in Markdown and designed to be used inside **Obsidian**, leveraging its internal linking, graph view, and tagging system for an interconnected learning experience.

## 🚀 Getting Started

1. **Install [Obsidian](https://obsidian.md/)** (free)
2. **Clone this repository**:
   ```bash
   git clone https://github.com/GNU-LuxTech/COMPTIA_Network_Plus_N10-009_Obsidian_Project.git
   ```
3. **Open the vault** in Obsidian:  
   `File → Open Folder as Vault` → select the `COMPTIA_Network_Plus_N10-009_Obsidian_Project/` folder inside the cloned repo
4. Start from the **main index**: `COMPTIA NETWORK+ N10-009.md`
